# 思绪盒子 Thoughts Box

> 本地优先的个人思绪整理工具 —— 把杂乱的念头、经历、情绪倒进盒子，再由整理与图谱帮你重新打开过去的记录。
>
> A local-first personal tool for capturing and re-organizing messy thoughts, episodes and emotions.

**当前状态：早期开发，V0 实现中。** 本快照对应工程骨架阶段（M0），业务功能尚未落地；对外接口与数据格式仍可能变化，请谨慎用于真实数据。

## 这是什么

Thoughts Box 是一个运行在自己电脑上的单用户记录应用。你随时把未经整理的内容写进来——一段经历、一个念头、一种情绪，不需要格式；之后由应用协助你重新使用这些记录：

- **记录与修订**：原始内容按版本保存，可以被修改而不丢失历史；全文检索覆盖当前与历史文本。
- **辅助整理**：应用依据一套公开的词表（36 个情绪概念、18 个主题概念）与实体记录，把自由文本关联到可浏览的结构上。整理结果默认是**候选**，经用户确认后才成为正式内容；用户的手工修正不会被任何自动重算覆盖。
- **局部图谱**：整理结果构成可导航的记录之间的关系网络，从任意一条记录出发看到它「关于谁、是什么情绪、属于什么主题、与哪些记录可能相关」。
- **睡前收束**：一个只做回顾与归档的日终模式，不推送待办、不催促处理。

所有数据保存在本机 SQLite 数据库中；无账号体系，无云依赖，本地服务仅监听 `127.0.0.1`。

## 开发路线

按里程碑推进，不承诺日期：M0 工程骨架（本快照）→ M1 记录 / 版本 / 搜索 / 备份 → M2 辅助整理与隐私关卡 → M3 局部图谱 / 建议队列 / 睡前模式 → M4 受限全局图谱与 V0 收尾。产品规格与设计文档不在本仓库发布；上文即为 V0 目标的完整自述。

## 项目原则

- **本地优先**：记录、整理结果、图谱、搜索全部存在本机 SQLite，服务只监听 `127.0.0.1`，固定端口，不自动切换。
- **云端是显式选项**：每条内容的处理方式独立标记；发往云端前必须经过逐条的「本次发送授权」，并向用户展示真实脱敏文本。不使用云端模式则永不外发。
- **删除是真的删除**：当前数据库内采用应用层硬删除，并留下不含原文的审计记录；但不回溯旧备份，也不承诺物理介质上绝对不可恢复——隐私声明只写做得到的事。
- **AI 是建议者，不是裁决者**：自动产生的情绪、主题、实体关联先进入候选与建议队列，由用户确认后才成为正式内容。
- **封闭枚举**：状态、关系类型、处理方式等取值集合全部固化在 `src/shared/constants/enums.json`，由 Schema 校验与测试断言共同守护，实现不得发明取值。

## 运行要求

- Node.js `>=24.18.0 <27`（依赖运行时内建的 `node:sqlite` 与 `crypto.randomUUIDv7`，版本过低或过高都会在启动自检中被明确拒绝）。
- 主要开发于 Windows；macOS / Linux 走 XDG 数据目录，不硬编码路径。

## 启动

```bash
npm install
npm run dev            # 同时拉起本地后端（8737）与前端（5173）
npm run typecheck      # 服务端 + 前端两套 tsconfig
npm test               # 全部验收断言
```

只起后端：`npm run start:server`；只起前端：`npm run start:web`。

## 数据在哪

- 运行时数据目录：`%LOCALAPPDATA%\ThoughtsBox\`（非 Windows：`$XDG_DATA_HOME` 或 `~/.local/share`）。
- 数据库、备份、日志、本地配置、实例锁都在该目录，**仓库目录不放私人数据**。
- 用 `TB_DATA_DIR=<目录>` 覆盖——测试与多实例开发必须用它隔离。
- 首次启动从 `config.example.json` 生成 `config.local.json`；模板只有占位值，密钥只经环境变量提供，配置文件中出现疑似密钥字面值会被直接拒绝。

## 仓库结构

```
src/server/   本地后端：HTTP 服务、启动自检、单实例锁、SQLite 适配层、
              迁移执行器、词表播种、配置加载
src/shared/   契约层：封闭枚举（constants/enums.json）、情绪与主题词表
              （vocab/）、Zod Schema、ID 前缀、契约指纹加载
src/web/      React 19 + Vite 7 前端（可视化层，不持有业务数据；当前为占位壳）
scripts/      开发启动器
tests/        vitest 验收断言（一律使用隔离数据目录，不触碰真实用户数据）
```
